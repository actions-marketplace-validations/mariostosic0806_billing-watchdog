1. Zero Application Telemetry, Self-Hosted Fonts & Client-Side Execution

The browser SQL/ORM/RLS auditor, storm simulator, and CSV/JSON subscription diff reconciler hosted at mariostosic0806.github.io/billing-watchdog/ run with zero application telemetry: zero analytics scripts, zero tracking cookies, and zero external Google Fonts requests (all .woff2 web fonts are self-hosted on the same origin or rendered via local system font stacks in compliance with EU GDPR standards, LG München Az. 3 O 17493/20). SQL schemas, TypeScript/ORM code, Stripe/database CSV or JSON exports, and BWV2E-... license tokens inspected in the browser are processed strictly in local browser memory (0 bytes uploaded). The Self-Hosted Pro v2 CLI and GitHub Action execute exclusively inside your own CI runners or servers; your database URLs and Stripe restricted keys never leave your infrastructure.

2. Static Web Hosting & Transient Edge CDN Logs

This static documentation and browser workbench site is served via GitHub Pages (operated by GitHub, Inc. and delivered over the Fastly edge CDN). Standard to any HTTPS web delivery, GitHub Pages / Fastly transiently process incoming HTTP connection metadata (such as visitor IP address, TLS handshake parameters, User-Agent header, and requested asset path) strictly for TLS content delivery, DDoS mitigation, and platform abuse prevention under GitHub's Privacy Statement. The operator does not receive, log, or store visitor IP addresses from GitHub Pages.
